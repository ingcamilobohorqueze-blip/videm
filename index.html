Marco Contractual y Telemático

Términos y Condiciones de Asistencia Técnica

1. Naturaleza Jurídica del Servicio

Videm opera exclusivamente como un servicio profesional independiente de consultoría técnica, configuración telemática y optimización de dispositivos multimedia para el hogar (Smart TVs, TV Boxes, barras de sonido y redes domésticas).

Videm NO es un proveedor de servicios de internet (ISP), ni un operador de televisión, ni comercializa, transmite, retransmite, aloja ni almacena contenido audiovisual protegido por leyes de propiedad intelectual.

2. Software Cliente y Código Abierto

Las interfaces de usuario utilizadas (como Stremio) corresponden a software de código abierto (*open source*) distribuido públicamente bajo sus respectivas licencias comunitarias. Videm no altera, recompila ni distribuye binarios modificados de dicho software.

3. Enlaces Telemáticos de Terceros (CDN)

Para garantizar la máxima tasa de transferencia (bitrate Remux 4K sin buffering), el servicio integra enlaces hacia redes de distribución de datos de alta velocidad (Real-Debrid). El usuario reconoce y autoriza a Videm a actuar como mandatario técnico para el aprovisionamiento, parametrización y mantenimiento de dichos enlaces.

4. Política Estricta de 1 Hogar / 1 IP

Para blindar la estabilidad de la conexión y prevenir bloqueos por parte de los proveedores de enlace CDN, el acceso está configurado para operar exclusivamente dentro de la red IP del domicilio residencial del cliente. El uso concurrente del enlace fuera de la red local del hogar o su compartición con terceros provocará la suspensión técnica automática por parte del proveedor sin responsabilidad para Videm.

5. Honorarios Profesionales

Las tarifas cobradas corresponden estrictamente a honorarios por consultoría, despliegue llave en mano, curaduría de catálogos y soporte técnico continuo durante el ciclo contratado (semestral o anual).
